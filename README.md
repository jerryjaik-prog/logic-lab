\# The Logic Lab 🧠



An educational browser-based game for students aged 10–15.



\## Features

\- 50 questions across 5 categories

\- Live score tracking

\- Auto progress

\- No retries

\- Final evaluation with congratulations

\- Safe, non-violent, educational content
